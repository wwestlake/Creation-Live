# Creation Live Capabilities

This document is the starting scope note for Creation Live.

Initial target areas:

- live scene switching
- cue stack and run-of-show control
- media, overlay, and graphics playback
- stream and program monitoring
- shared Creation language integration for live-safe domains only

Deliberate non-goals for the scaffold:

- RTMP / ingest implementation
- final switching backend
- hardware panel integration
- shared-language execution of game-engine-only or DAW-only node domains
